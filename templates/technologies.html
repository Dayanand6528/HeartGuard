System Architecture

Technologies & Stack Breakdown

A deep dive into the 100% offline technologies powering HeartGuard's prediction engine, database, and medical AI chatbot.

Python Flask Backend

Core Server & REST API

Flask provides lightweight, high-performance routing for web pages, JSON REST endpoints, session authentication, and direct integration with Python ML packages.

Scikit-Learn ML Model

Random Forest Classifier

Random Forest Ensemble algorithm with 150 decision trees trained on Kaggle UCI heart disease features. Features are normalized using Scikit-Learn's StandardScaler.

XAMPP MySQL Database

Dual MySQL & SQLite Driver

Connects to XAMPP MySQL server (localhost:3306) storing users, predictions, contact forms, and chat logs. Includes automatic fallback to SQLite when XAMPP is offline.

Offline Medical AI Assistant

Strictly Medical Domain AI

Local offline neural AI engine integrated via secure local REST API. Programmed to strictly answer medical and health queries while rejecting non-medical requests. Zero external cloud API calls!

HTML5 & Vanilla CSS3

Glassmorphism Design System

Clean custom Vanilla CSS with custom properties, smooth CSS animations (heartbeat, pulse waves), glassmorphism backdrop blurs, and mobile responsive flex/grid layouts.

Role-Based Authentication

Patient, Doctor, Admin

Secure session handling with Werkzeug SHA-256 password hashing. Isolates views for Patients (risk reports), Doctors (clinical review), and Administrators (system logs).
